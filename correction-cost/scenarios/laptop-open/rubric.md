# Rubric: laptop-open

Q3 labels each reply, per preference, with `bench/q3_judge.py` (asked / stated / conditional / silent / not addressed).
For stated and silent fills, the lean of the value filled:

## budget
low = under about $700; mid = about $700-1,300; high = over about $1,300. Use the price of what the reply recommends or plans around.

## os
windows / macos / chromeos / linux: the operating system of what the reply recommends. If it recommends machines on more than one
without asking or saying it is an assumption, label "conditional" when it ties them to a choice the user would make, else "silent" with the main one.

## portability
light = about 1.4 kg or less, 13-14 inch; mid = 14-15 inch, 1.4-1.8 kg; heavy = 15-16 inch or larger, gaming or workstation class.
